# 🤖 How AI Coding Assistants Are Changing Software Development

## 📖 Overview

This repository contains the research materials, documentation, and presentation for our group research project on **"How AI Coding Assistants Are Changing Software Development."**

The purpose of this project is to investigate how AI-powered coding assistants are transforming software development by improving productivity, assisting with code generation, debugging, documentation, and learning. The project also explores the challenges, ethical concerns, and future impact of these tools on software engineering.

---

## ❓ Research Question

> **How are AI coding assistants changing software development, and what are their benefits, challenges, and future implications?**

---

## 🎯 Objectives

- Understand what AI coding assistants are and how they work.
- Explore popular AI coding tools used by developers.
- Analyze the benefits of AI-assisted software development.
- Investigate the limitations, risks, and ethical concerns.
- Discuss the future of AI in software engineering.
